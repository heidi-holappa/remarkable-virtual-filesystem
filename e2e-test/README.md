# End-to-end test utilities

## Test Reports

The test report directory contains a template for manual end-to-end testing. The template should be updated any time new functionalities are added to the reMarkable-VFS application. Before each release, a report should be then created by executing all test cases in the template. 


## End-to-end test material

The directory `test/` contains a simple collection of files ands sub-directories for end-to-end testing. Please feel free to expand the test material as necessary.
